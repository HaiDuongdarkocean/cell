Cell Design System

Shape & effect = YouTube DS · Color = Cell semantic tokens · 16 universal components

1

Content-first

Flat, zero elevation, hairline 1px border, whitespace separation. UI chrome gets out of the way — never competes with content.

2

Alpha-based states

Hover/active use surface-hover fill (theme-agnostic). Focus = 2px solid ring offset 2px (WCAG 2.4.7). No solid color flashes.

3

Shape ≠ Color

Shape/effect tokens (radius 18px pill / 10px card / 12px dialog, shadow none) follow YouTube. Color tokens stay Cell (primary blue, surface slate).
