Feasibility — Meta/Facebook DS → Universal Panel

  • Architecture: Current UniversalPanel.tsx already has right-edge fixed panel, tab bar, header toggles, and React mount pattern. Feasibility is high.
  • Token migration: Need to replace Cell tokens (--space-*, --color-background) with Meta/Astryx semantic tokens (--spacing-*, --color-background-surface).
  • Components: Reuse existing @/shared/ui atoms (Button, IconButton, Toggle, Input, Select) but restyle to 4px grid, 12px/16px radius, accent focus rings.
  • Dictionary tab: Phase 1 wraps existing vanilla popup dictionary into the left pane. Phase 2 rewrites as React. Card Creator renders in right pane via useCardCreatorState.
  • Settings tab: Reuse SettingsDialogContent inside the panel body with a max-width cap (≤960px) so it does not stretch.
  • Mobile: Switch to bottom-sheet / full-screen with bottom tab bar. Card creator becomes stacked or bottom sheet.
  • Risks: Fullscreen video reparenting, z-index stacking, content-script theme injection, and dictionary vanilla→React handoff require careful integration testing.
