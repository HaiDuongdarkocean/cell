## Deviations from spec text (both justified, flagged)

1. **`useLayoutEffect` instead of spec'd `useEffect`** for the panel's layer (`UniversalPanel.tsx:147`). Correct call — React runs children's passive effects before the parent's, so a descendant overlay mounting open in the same commit would otherwise register *under* the panel layer (spec's exception analysis was inverted). Layout effects run before all passive effects, fixing the ordering. Documented in code + `docs/2-architechture-system.md`.
2. **`hasEscapeLayers` export added to `escapeLayerStack.ts:76`** + yield guard in `PlayerModeOverlay.tsx:507`. Spec's row said only "move to window capture"; without the guard the capture listener would steal Escape from stacked layers inside player mode (its more-menu `Sheet`, the panel) — previously the stack's document-capture listener consumed those keys before this bubble handler ran, so the guard is required for parity. **Consequence vs recorded delta D6**: with the panel open during player mode, Escape now closes the panel (stack top) instead of exiting player mode — D6's "the capture consumer wins alone" wording is stale for this combination; the invariant "one Escape = one layer, inner-first" still holds. `regionSelector` deliberately has no yield guard (spec: "the active selection always wins").
