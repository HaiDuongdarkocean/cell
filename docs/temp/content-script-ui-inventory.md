## 3. Cố ý giữ vanilla

- **Token spans** (web text + subtitle): phải ở light DOM để `Range`, `Selection`, `getBoundingClientRect`, lookup trigger hoạt động đúng trên text host.
- **Word/sentence highlight**: phải ở light DOM để đặt overlay đúng vị trí từ trong trang.
- Plan `tasks/plan-content-script-react-shadow-root.md` ghi rõ 2 nhóm này **không** chuyển vào Shadow DOM/React (phase 4/5).

## 4. Tóm tắt

Các màn hình lớn (popup, badge, FAB, universal/settings/card creator dialogs, subtitle panels) đã là React + Shadow DOM. Các màn hình/surface còn vanilla ở content-script chủ yếu là text-decoration / highlight / toast nhỏ / drag hint và legacy fallback. Token spans và word highlight được giữ vanilla theo thiết kế.
