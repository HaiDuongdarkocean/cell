- Hoặc: mở tab mới → Reader tab

---

## 4. Mô tả chi tiết chức năng

### 4.1 Mở file

- File picker: chọn .epub hoặc .pdf
- Drag-drop file vào giao diện Reader
- Parse và render nội dung trong tab mới

### 4.2 Parse EPUB

- Giải nén .epub (ZIP)
- Parse OPF manifest để lấy thứ tự chapters
- Render HTML content của từng chapter
- Hỗ trợ: EPUB 2.0, EPUB 3.0

### 4.3 Parse PDF

- Render PDF bằng PDF.js
- Extract text layer để tokenize
- Hỗ trợ PDF có text layer (không hỗ trợ PDF scan)

### 4.4 Danh sách sách đã mở

- Lưu danh sách sách đã mở (tên file, ngày mở, tiến độ)
- Mở lại từ danh sách mà không cần chọn file lại

## 7. Yêu cầu phi chức năng

- Mở file EPUB < 3 giây cho file 10 MB
- Render PDF dùng PDF.js (không cần plugin)
- Hoạt động hoàn toàn offline
- File không được upload lên server — chỉ xử lý local
