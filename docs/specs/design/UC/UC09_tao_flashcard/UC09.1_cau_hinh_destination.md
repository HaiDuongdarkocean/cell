## 3. Menu / Điểm vào

- Settings → tab **Flashcard** → **Destination**
- Hoặc: Card Creator → dropdown "Deck" → "Cấu hình..."

---

## 4. Mô tả chi tiết chức năng

### 4.1 Chọn đích lưu

| Đích | Mô tả |
|---|---|
| **Ocean Memory** | SRS nội bộ của Orca (mặc định) |
| **Anki** | Xuất qua AnkiConnect (cần Anki đang mở) |

### 4.2 Cấu hình Ocean Memory

- Chọn deck mặc định
- Chọn card type mặc định

### 4.3 Cấu hình Anki

- Chọn Anki deck
- Chọn Anki note type
- Map fields: Orca field → Anki field

### 4.4 Lưu cấu hình

- Cấu hình được lưu per-language-profile
- Dùng cho tất cả lần tạo card tiếp theo
