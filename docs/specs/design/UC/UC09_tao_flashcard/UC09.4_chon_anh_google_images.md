## 3. Menu / Điểm vào

- Card Creator → field Image → **[🔍 Tìm ảnh]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Tìm kiếm ảnh

- Query mặc định = target word
- Người dùng có thể sửa query
- Scrape Google Images (không dùng API chính thức)
- Hiển thị grid 12 ảnh

### 4.2 Chọn ảnh

- Click ảnh → chọn làm ảnh cho card
- Ảnh được download và lưu local (không link trực tiếp)

### 4.3 Upload ảnh từ máy

- Nút "Upload từ máy" → file picker ảnh
- Hỗ trợ: .jpg, .png, .gif, .webp

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Tìm ảnh Google Images | ❌ | ✅ | ✅ | — |
| Upload ảnh từ máy | ✅ | ✅ | ✅ | — |

## 7. Yêu cầu phi chức năng

- Tải grid ảnh < 3 giây
- Ảnh được lưu local (không phụ thuộc URL Google)
- Kích thước ảnh tối đa: 500KB (resize nếu cần)
