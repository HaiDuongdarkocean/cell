## 3. Menu / Điểm vào

- Bookmark Manager → chọn bookmark → **[✨ Tạo flashcard]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Auto-fill từ bookmark

- **Sentence field** = nội dung đoạn đã bookmark
- **Source** = URL trang web
- Các field khác: để trống, người dùng điền thêm

### 4.2 Mở Card Creator

- Sau auto-fill: mở Card Creator để review và bổ sung
- Người dùng thêm target word, definition, audio, ảnh
