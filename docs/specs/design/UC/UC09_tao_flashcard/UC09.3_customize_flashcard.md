## 4. Mô tả chi tiết chức năng

### 4.1 Các field có thể chỉnh sửa

| Field | Loại input |
|---|---|
| Target word | Text input |
| Sentence | Textarea |
| Sentence translation | Textarea |
| Definition | Textarea (rich text) |
| Word audio | File picker / TTS / Forvo |
| Sentence audio | File picker / Cắt lại từ video |
| Image | Grid picker (UC09.4) / Upload / Screenshot (UC09.5) |
| POS | Dropdown |
| Notes | Textarea |
| Tags | Tag input (UC09.6) |
| Deck | Dropdown |

### 4.2 Preview card

- Preview real-time: mặt trước và mặt sau của card
- Chuyển đổi giữa mặt trước/sau

### 4.3 Lưu card

- Nút "Lưu" → lưu vào destination đã cấu hình
- Nút "Lưu và tạo tiếp" → lưu và mở Card Creator mới

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Chỉnh sửa tất cả fields | ✅ | ✅ | ✅ | — |
| Preview card | ✅ | ✅ | ✅ | — |
| Lưu card | ✅ (≤625) | ✅ (≤625) | ✅ | — |
