## 4. Mô tả chi tiết chức năng

### 4.1 Thêm tag

- Gõ tên tag → nhấn Enter hoặc dấu phẩy để thêm
- Tự động thêm prefix # nếu chưa có
- Autocomplete từ tags đã dùng trước đó

### 4.2 Xóa tag

- Click ✕ trên tag để xóa

### 4.3 Tags gợi ý

- Gợi ý tags phổ biến: #IELTS, #business, #slang, #formal, #idiom, #phrasal-verb

### 4.4 Dùng tags để lọc

- Tags được dùng để lọc trong Flashcard Manager (UC10.2)
- Dùng để tạo filtered review session (UC12.2)
