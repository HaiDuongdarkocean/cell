## 3. Menu / Điểm vào

- Toolbar popup → tab **Memory** → **[Quản lý cards]**
- Hoặc: Web App Dashboard → Cards tab

---

## 4. Mô tả chi tiết chức năng

### 4.1 Danh sách cards

Mỗi card hiển thị:
- Target word (mặt trước)
- Câu ví dụ (preview)
- Deck
- Trạng thái SRS: New / Learning / Review / Mature
- Ngày tạo / ngày ôn tiếp theo

### 4.2 Tìm kiếm

- Tìm theo target word
- Tìm theo nội dung sentence

### 4.3 Sắp xếp

- Theo ngày tạo (mới nhất trước)
- Theo ngày ôn tiếp theo
- Theo trạng thái SRS
- Theo alphabet
