## 4. Mô tả chi tiết chức năng

### 4.1 Các bộ lọc

| Filter | Tùy chọn |
|---|---|
| Deck | Chọn 1 hoặc nhiều deck |
| Card type | Vocabulary / Sentence / ... |
| Trạng thái SRS | New / Learning / Review / Mature |
| Ngày tạo | Hôm nay / Tuần này / Tháng này / Tùy chỉnh |
| POS | Noun / Verb / Adj / ... |
| Tags | Chọn 1 hoặc nhiều tags |

### 4.2 Kết hợp filter

- Có thể kết hợp nhiều filter cùng lúc (AND logic)
- Hiển thị số cards thỏa điều kiện
