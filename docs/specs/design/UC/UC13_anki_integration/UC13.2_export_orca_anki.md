- **Mã UC:** UC13.2
- **Đối tượng sử dụng:** Free User, Premium User

---

## 2. Điều kiện tiên quyết

- Người dùng đã đăng nhập
- Anki đang mở với AnkiConnect addon đã cài (UC13.1)
- Có ít nhất 1 deck trong Ocean Memory

---

## 3. Menu / Điểm vào

- Settings → Anki → **[Export sang Anki]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Chọn deck nguồn

- Chọn deck Ocean Memory muốn export

### 4.2 Chọn Anki deck đích

- Dropdown danh sách Anki decks (fetch từ AnkiConnect)
- Hoặc tạo Anki deck mới

### 4.3 Map fields

- Hiển thị bảng map: Orca field → Anki field
- Tên trùng nhau → tự động map
- Tên khác → người dùng chọn thủ công

### 4.4 Export

- Gửi cards qua AnkiConnect API (`addNotes`)
- Hiển thị progress
- Báo cáo: số cards thành công / thất bại
