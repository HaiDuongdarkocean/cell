## 2. Điều kiện tiên quyết

- AnkiConnect đã kết nối

---

## 3. Menu / Điểm vào

- Settings → Anki → **[Cấu hình sync]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Selective sync

- Chọn từng cặp deck Orca ↔ Anki để sync
- Bật/tắt sync cho từng cặp

### 4.2 Hướng sync

- **2 chiều:** Orca ↔ Anki (mặc định)
- **Chỉ Orca → Anki:** export một chiều
- **Chỉ Anki → Orca:** import một chiều
