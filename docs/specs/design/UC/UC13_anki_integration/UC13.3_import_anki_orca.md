## 2. Điều kiện tiên quyết

- AnkiConnect đang chạy
- Có deck trong Anki muốn import

---

## 3. Menu / Điểm vào

- Settings → Anki → **[Import từ Anki]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Chọn Anki deck

- Dropdown danh sách Anki decks

### 4.2 Map fields

- Tự động map fields có tên trùng
- Người dùng map thủ công cho fields khác tên

### 4.3 Convert SRS progress

- Convert SM-2 (Anki) → FSRS (Orca)
- Dựa trên: interval, ease factor, repetitions
- Công thức convert: ước tính stability từ interval

### 4.4 Import

- Import nội dung + SRS progress
- Hiển thị progress bar
