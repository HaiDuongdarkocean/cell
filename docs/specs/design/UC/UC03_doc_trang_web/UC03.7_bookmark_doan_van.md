- Hoặc: bôi đen → floating mini toolbar của Orca

---

## 4. Mô tả chi tiết chức năng

### 4.1 Tạo bookmark

1. Người dùng bôi đen đoạn văn muốn bookmark
2. Context menu hoặc mini toolbar hiện ra
3. Nhấn "Bookmark đoạn này"
4. Dialog nhỏ xuất hiện để thêm tags (tùy chọn)
5. Nhấn "Lưu" → bookmark được tạo

### 4.2 Dữ liệu lưu kèm bookmark

- **Nội dung:** text đã bôi đen
- **Context:** 50 ký tự trước và sau đoạn được chọn
- **URL:** URL trang web hiện tại
- **Title:** tiêu đề trang web
- **Timestamp:** thời gian tạo
- **Tags:** danh sách tags người dùng thêm
- **Language:** ngôn ngữ của đoạn văn

### 4.3 Hiển thị trên trang

- Đoạn đã bookmark hiển thị **icon bookmark nhỏ** (🔖) bên cạnh
- Hover icon → tooltip hiển thị tags và ngày tạo
- Click icon → mở bookmark trong Bookmark Manager (UC14.2)

### 4.4 Giới hạn

- **Free User:** tối đa 500 bookmarks
- **Premium User:** không giới hạn [Phase 2]

### Bảng phân quyền hiển thị nút

## 7. Yêu cầu phi chức năng

- Tạo bookmark < 200ms
- Icon bookmark không làm thay đổi layout trang
- Bookmark persist qua các lần reload trang (lưu theo URL + text hash)
- Hoạt động offline (lưu local, sync Drive khi có mạng)
