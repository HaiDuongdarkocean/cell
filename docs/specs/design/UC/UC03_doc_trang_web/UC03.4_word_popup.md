## 4. Mô tả chi tiết chức năng

### 4.1 Kỹ thuật Shadow DOM

- Popup được render trong **Shadow DOM** isolated
- CSS của trang web không ảnh hưởng đến popup
- Popup không bị che bởi z-index của trang

### 4.2 Nội dung popup

**Header:**
- Target word (font lớn, bold)
- Frequency rank (ví dụ: #1,234 / 60,000)
- POS tags (noun, verb, adj...)
- Pinyin (chỉ hiển thị với tiếng Trung)
- Nút phát âm thanh từ (Forvo API → fallback TTS)
- Status badge hiện tại + nút đổi status nhanh

**Body (tabs):**
- **Tab từ điển:** definition từ mỗi từ điển active (tab riêng cho mỗi từ điển)
  - Definitions, examples, synonyms
- **Tab AI:** [30 lần/ngày Free]
  - "Giải thích từ này trong ngữ cảnh câu đang đọc"
  - "Phân tích ngữ pháp câu đang đọc"
  - Powered by WebLLM Qwen2.5 hoặc Ollama fallback

**Footer:**
- Link từ điển ngoài: Cambridge / Jisho / MDBG / Wiktionary (theo ngôn ngữ)
- Nút **[+ Thêm flashcard]** → UC09.2

### 4.3 Trigger modes

| Mode | Hành vi |
|---|---|
| Click | Nhấn vào từ → popup mở ngay |
| Hover | Di chuột vào từ, giữ 300ms → popup mở |
| Modifier+hover | Giữ Shift/Alt + hover → popup mở ngay (không delay) |
| Auto (video pause) | Video dừng → popup mở từ chưa biết trong subtitle |

### 4.4 Đóng popup

- Click ra ngoài popup
- Nhấn Escape
- Click vào từ khác (popup chuyển sang từ mới)

### 4.5 Giới hạn AI

- Free User: 30 lần AI/ngày (tổng cộng cả giải thích từ + phân tích câu)
- Khi hết quota: hiển thị "Đã dùng hết 30 lần AI hôm nay. Reset lúc 00:00."
- Premium User: không giới hạn [Phase 2]

## 7. Yêu cầu phi chức năng

- Popup mở trong < 100ms (lookup từ SQLite local)
- Shadow DOM đảm bảo không bị CSS trang web ảnh hưởng
- Popup tự điều chỉnh vị trí để không bị cắt bởi cạnh màn hình
- Hoạt động offline (definition từ SQLite, audio TTS local)
- AI response trong < 5 giây sau khi model đã warm-up (WebLLM local)
- Popup không block scroll trang web
