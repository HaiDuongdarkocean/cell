- Người dùng đã đăng nhập

---

## 3. Menu / Điểm vào

- Toolbar popup → tab **Bookmarks**
- Hoặc: Web App Dashboard → Bookmarks tab

---

## 4. Mô tả chi tiết chức năng

### 4.1 Danh sách bookmarks

Mỗi bookmark hiển thị:
- Nội dung đoạn văn (preview 100 ký tự)
- URL và title trang
- Tags
- Ngày tạo

### 4.2 Tìm kiếm

- Tìm theo nội dung text
- Tìm theo URL

### 4.3 Bộ lọc

- Theo tags
- Theo nguồn (web / video / podcast / EPUB)
- Theo ngày

### 4.4 Actions

- Mở URL gốc
- Tạo flashcard (UC14.4)
- Gửi email (UC14.3)
- Xóa (UC14.5)
