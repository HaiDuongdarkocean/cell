---

## 2. Điều kiện tiên quyết

- Người dùng đã đăng nhập
- Có bookmark đã tạo

---

## 3. Menu / Điểm vào

- Bookmark Manager → bookmark → **[🗑️ Xóa]**
- Hoặc: chọn nhiều → **[🗑️ Xóa đã chọn]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Xóa đơn lẻ

- Nhấn xóa → xác nhận → xóa bookmark
- Icon bookmark trên trang web biến mất

### 4.2 Xóa hàng loạt

- Chọn nhiều bookmark → xóa tất cả
- Xác nhận: "Xóa [n] bookmarks?"
