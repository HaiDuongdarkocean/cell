---

## 3. Menu / Điểm vào

- Settings → **Daily Goal**
- Ocean Memory Home → **[⚙️ Mục tiêu]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Loại mục tiêu

| Loại | Mô tả |
|---|---|
| Cards/ngày | Số cards ôn tập mỗi ngày (ví dụ: 50 cards) |
| Phút/ngày | Số phút học mỗi ngày (ví dụ: 20 phút) |

### 4.2 Hiển thị progress

- Progress bar trên Ocean Memory Home
- Notification khi đạt mục tiêu

### 4.3 Streak

- Streak tăng khi đạt mục tiêu ngày
- Streak reset về 0 nếu bỏ 1 ngày

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Đặt mục tiêu | ❌ | ✅ | ✅ | — |
| Xem progress | ✅ | ✅ | ✅ | — |
