## 4. Mô tả chi tiết chức năng

### 4.1 Định dạng hỗ trợ

| Định dạng | Mô tả | Ví dụ |
|---|---|---|
| Newline-separated | Mỗi dòng 1 từ | apple\nbanana\n... |
| CSV | word[,status] | apple,known\nbanana,tracking |
| JSON | Array of strings hoặc objects | ["apple","banana"] |
| Free-text | Đoạn văn bình thường | "I love eating apples..." |

### 4.2 Quy trình import

1. Chọn định dạng hoặc để auto-detect
2. Paste text hoặc upload file
3. Preview: hiển thị số từ phát hiện, số từ đã có trong tracker
4. Chọn trạng thái mặc định cho từ mới (mặc định: "Đã học")
5. Nhấn Import

### 4.3 Free-text auto-tokenize

- Nếu nhập đoạn văn: tự động tokenize → extract unique words
- Đánh dấu tất cả là "Đã học" (người dùng biết đoạn văn này)

### 4.4 Xử lý trùng lặp

- Từ đã có trong tracker: bỏ qua (không ghi đè trạng thái)
- Hoặc: người dùng chọn "Ghi đè trạng thái hiện tại"

### Bảng phân quyền hiển thị nút
