## 3. Menu / Điểm vào

- Tab Clipboard → nút **[▶ Đọc]** trên session

---

## 4. Mô tả chi tiết chức năng

### 4.1 TTS đọc text

- Nhấn **[▶ Đọc]** → TTS đọc toàn bộ session từ đầu
- Highlight câu đang đọc real-time
- TTS engine: Web Speech API (offline) hoặc Edge TTS (online, chất lượng cao)

### 4.2 Điều hướng

| Nút | Hành động |
|---|---|
| ▶/⏸ | Play/Pause |
| ◄ | Câu trước |
| ► | Câu tiếp theo |
| ↺ | Lặp câu hiện tại |
| ↻ | Lặp đoạn (A-B) |

### 4.3 Tốc độ đọc

- 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| TTS đọc text | ❌ | ✅ | ✅ | — |
| Điều hướng câu | ❌ | ✅ | ✅ | — |
| Chọn tốc độ | ❌ | ✅ | ✅ | — |
