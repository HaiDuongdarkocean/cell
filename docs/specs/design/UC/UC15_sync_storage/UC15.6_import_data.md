## 3. Menu / Điểm vào

- Settings → Data → **[⬆️ Import data]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Chọn file

- File picker: chọn .json hoặc .zip
- Validate format trước khi import

### 4.2 Chế độ import

- **Merge:** merge với data hiện tại (per-record, mới hơn thắng)
- **Replace:** xóa toàn bộ data hiện tại và thay bằng file import

### 4.3 Preview

- Hiển thị số records sẽ được import
- Cảnh báo nếu chọn Replace
