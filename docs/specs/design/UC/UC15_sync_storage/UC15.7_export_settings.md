## 2. Điều kiện tiên quyết

---

## 3. Menu / Điểm vào

- Settings → **[⬇️ Export settings]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Dữ liệu export

- Keyboard shortcuts
- Màu highlight
- Theme
- UI language
- TTS settings
- AI settings + prompts
- Daily reminder
- Blacklist
- Các cài đặt khác

### 4.2 Định dạng

- JSON file: `orca_settings_[ngày].json`
