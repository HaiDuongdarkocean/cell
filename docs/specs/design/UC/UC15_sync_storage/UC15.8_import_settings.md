## 2. Điều kiện tiên quyết

- Có file settings JSON từ UC15.7

---

## 3. Menu / Điểm vào

- Settings → **[⬆️ Import settings]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Import

- Chọn file JSON
- Validate format
- Preview: hiển thị settings sẽ được áp dụng
- Xác nhận → apply settings

### 4.2 Merge vs Replace

- Mặc định: Replace (settings là toàn bộ, không merge từng phần)
- Tùy chọn: chọn chỉ import một số loại settings
