## 2. Điều kiện tiên quyết

- Người dùng đã đăng nhập

---

## 3. Menu / Điểm vào

- Settings → Data → **[⬇️ Export data]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Dữ liệu được export

- Flashcards (nội dung + FSRS history)
- Vocabulary tracker
- Bookmarks
- Settings
- Deck structure

### 4.2 Định dạng

- **JSON:** chỉ text data (không có media)
- **ZIP:** text data + media files (audio, image)

### 4.3 Tùy chọn

- Chọn loại data muốn export
- Chọn định dạng

### Bảng phân quyền hiển thị nút

|---|---|---|---|---|
| Export data | ❌ | ✅ | ✅ | — |

## 7. Yêu cầu phi chức năng

- Export JSON < 5 giây
- Export ZIP chạy ở background (có thể lâu hơn với nhiều media)
- File export có thể import lại (UC15.6)
