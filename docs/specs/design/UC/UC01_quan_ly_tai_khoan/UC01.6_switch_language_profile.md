## 2. Điều kiện tiên quyết

- Người dùng có ít nhất 2 language profile (Premium)
- Tất cả từ điển của profile đích đã được download

---

## 3. Menu / Điểm vào

**Toolbar popup** → dropdown chọn ngôn ngữ (1 click)

---

## 4. Mô tả chi tiết chức năng

### 4.1 Hiển thị dropdown ngôn ngữ

- Toolbar popup hiển thị ngôn ngữ đang active với flag quốc gia
- Click vào → dropdown hiển thị tất cả language profile đã tạo
- Profile đang active được đánh dấu ✓

### 4.2 Hành vi sau khi switch

- Hệ thống reload content script trên tab hiện tại
- Highlight từ vựng được cập nhật theo profile mới (từ điển + vocabulary status mới)
- Floating badge cập nhật thống kê theo profile mới
- Toolbar popup hiển thị stats của profile mới
- **Không ảnh hưởng** đến data của profile cũ

### 4.3 Phân quyền

| Tier | Hành vi |
|---|---|
| Guest | Không có dropdown — chỉ 1 ngôn ngữ |
| Free User | Không có dropdown — chỉ 1 ngôn ngữ |
| Premium User | Có dropdown switch ngôn ngữ |
