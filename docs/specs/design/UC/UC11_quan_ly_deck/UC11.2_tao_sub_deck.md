## 2. Điều kiện tiên quyết

- Người dùng đã đăng nhập
- Có ít nhất 1 deck parent

---

## 3. Menu / Điểm vào

- Deck Manager → hover deck → **[+ Sub-deck]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Cấu trúc sub-deck

- Sub-deck thuộc về 1 deck parent
- Tên hiển thị: "Parent::Sub" (kiểu Anki)
- Tối đa 3 cấp lồng nhau

### 4.2 Ôn tập

- Ôn deck parent = ôn tất cả sub-decks
- Ôn sub-deck riêng lẻ cũng được

### 4.3 Daily limits

- Sub-deck có thể có daily limits riêng
- Hoặc kế thừa từ parent deck
