## 3. Menu / Điểm vào

- Toolbar popup → tab Memory → **[+ Tạo deck]**
- Hoặc: Deck Manager → **[+ Tạo deck]**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Thông tin deck

- **Tên deck** (bắt buộc)
- **Mô tả** (tùy chọn)
- **FSRS settings riêng:**
  - New cards/day (mặc định: 20)
  - Review limit/day (mặc định: 200)
  - FSRS parameters (mặc định: global settings)

### 4.2 Daily limits

- Giới hạn new cards và reviews mỗi ngày cho deck này
- Có thể override global settings

### 4.3 Giới hạn

- **Free User:** tối đa 10 decks
- **Premium User:** không giới hạn [Phase 2]

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Tạo deck | ❌ | ✅ (≤10) | ✅ [Phase 2] | — |
