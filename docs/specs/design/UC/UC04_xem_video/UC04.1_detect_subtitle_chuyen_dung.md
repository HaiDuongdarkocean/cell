## 4. Mô tả chi tiết chức năng

### 4.1 Site Adapters

**YouTube:**
- Intercept request đến `youtube.com/api/tiledtext` (XML) hoặc `youtube.com/youtubei/v1/get_transcript` (JSON)
- Parse XML/JSON subtitle → chuẩn hóa thành format nội bộ `{start, duration, text}`
- Detect tất cả track ngôn ngữ có sẵn
- Hỗ trợ auto-generated captions (ASR) và manual captions

**Netflix:**
- Intercept request đến `nflxvideo.net` chứa subtitle TTML/DFXP
- Parse TTML/DFXP → chuẩn hóa
- Detect ngôn ngữ từ metadata response

**iQIYI:**
- Intercept JSON subtitle từ API nội bộ
- Parse và chuẩn hóa

### 4.2 Chọn track ngôn ngữ

- Nếu có nhiều track ngôn ngữ: hiển thị dropdown chọn ngôn ngữ học và ngôn ngữ mẹ đẻ
- Mặc định: chọn ngôn ngữ học hiện tại của profile
- Lưu lựa chọn per-site

### 4.3 Sau khi detect thành công

- Subtitle được load vào hệ thống dual subtitle (UC04.6)
- Floating bar hiển thị "✅ Subtitle đã tải"
- Bắt đầu highlight từ trong subtitle (UC03.1)

### 4.4 Fallback

- Nếu site adapter thất bại → thử generic interceptor (UC04.2)
- Nếu không có subtitle → hiển thị tùy chọn: Tạo bằng Whisper (UC04.3) / Import thủ công (UC04.4) / Tìm online (UC04.5)

## 7. Yêu cầu phi chức năng

- Detect subtitle trong < 2 giây sau khi video bắt đầu phát
- Intercept không làm chậm tải trang
- Cập nhật adapter khi YouTube/Netflix thay đổi API (maintainable)
- Hoạt động với cả video có DRM (chỉ intercept subtitle, không intercept video)
