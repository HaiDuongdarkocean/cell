## 4. Mô tả chi tiết chức năng

### 4.1 Tùy chọn xuất

| Tùy chọn | Nội dung |
|---|---|
| Subtitle gốc | Subtitle ngôn ngữ học (chưa chỉnh sửa) |
| Bản dịch | Subtitle ngôn ngữ mẹ đẻ |
| Dual (song ngữ) | Cả 2 subtitle ghép vào 1 file |

### 4.2 Định dạng xuất

- **.srt** (SubRip) — phổ biến nhất
- **.vtt** (WebVTT) — chuẩn web

### 4.3 Tên file tự động

- Tên file = tiêu đề video + ngôn ngữ + định dạng
- Ví dụ: `Breaking_Bad_S01E01_en.srt`

## 7. Yêu cầu phi chức năng

- Xuất file < 1 giây cho subtitle 2 giờ
- Encoding UTF-8 với BOM cho .srt (tương thích Windows)
- Dual subtitle: 2 dòng liên tiếp cho mỗi timestamp
