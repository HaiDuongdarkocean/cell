## 3. Menu / Điểm vào

- Floating bar video → **[🔍 Tìm subtitle online]**
- Hoặc: dialog gợi ý khi không detect được subtitle

---

## 4. Mô tả chi tiết chức năng

### 4.1 Auto-search

- Hệ thống tự động lấy tiêu đề video từ DOM (`<title>`, `<h1>`, metadata)
- Gửi query đến OpenSubtitles API
- Lọc kết quả theo ngôn ngữ học hiện tại

### 4.2 Hiển thị kết quả

Mỗi kết quả hiển thị:
- Tên file subtitle
- Ngôn ngữ
- Rating (số sao)
- Số lượt download
- Thời lượng (để so sánh với video)

### 4.3 Preview trước khi chọn

- Click "Preview" → hiển thị 5 dòng đầu của subtitle
- Giúp người dùng xác nhận đúng subtitle

### 4.4 Download và apply

- Chọn subtitle → download tự động → parse → apply vào video
- Chọn vai trò: ngôn ngữ học hoặc ngôn ngữ mẹ đẻ

### 4.5 Tìm kiếm thủ công

- Nếu auto-search không tìm được: ô input để nhập tiêu đề thủ công

## 7. Yêu cầu phi chức năng

- Tìm kiếm và hiển thị kết quả < 3 giây
- Cache kết quả tìm kiếm 24 giờ (tránh gọi API lặp lại)
- Tuân thủ rate limit của OpenSubtitles API
- Không lưu subtitle đã download lên Drive (chỉ lưu local session)
