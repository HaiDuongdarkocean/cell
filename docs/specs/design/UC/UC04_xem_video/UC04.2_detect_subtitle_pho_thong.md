## 4. Mô tả chi tiết chức năng

### 4.1 Phương thức detect

**Phương thức 1 — DOM `<track>` element:**
- Scan DOM tìm `<track kind="subtitles">` hoặc `<track kind="captions">` trong `<video>`
- Parse src attribute → fetch file .vtt/.srt
- Hỗ trợ multiple tracks (nhiều ngôn ngữ)

**Phương thức 2 — Network intercept:**
- Service Worker intercept các request có extension `.vtt`, `.srt`, `.ass`, `.ssa`
- Cache response và parse
- Áp dụng cho subtitle được load dynamically

### 4.2 Xử lý nhiều video trên trang

- Nếu trang có nhiều `<video>` element: hiển thị badge nhỏ trên mỗi video
- Người dùng click badge để chọn video muốn học
- Chỉ 1 video active tại một thời điểm

### 4.3 Load thủ công (Ctrl+Shift+F)

- Mở dialog chọn file subtitle từ máy
- Hoặc nhập URL của file subtitle
- Parse và áp dụng cho video đang phát

### 4.4 Định dạng hỗ trợ

| Định dạng | Mô tả |
|---|---|
| .vtt | WebVTT — chuẩn web |
| .srt | SubRip — phổ biến nhất |
| .ass / .ssa | Advanced SubStation Alpha |

### 4.5 Encoding

- Auto-detect: UTF-8, UTF-16, Shift-JIS, GB2312

## 7. Yêu cầu phi chức năng

- Network intercept không làm chậm tải trang
- Parse subtitle file < 500ms cho file 1,000 dòng
- Hoạt động với video HTML5 native và các player phổ biến (Video.js, Plyr)
- Không intercept request không liên quan đến subtitle
