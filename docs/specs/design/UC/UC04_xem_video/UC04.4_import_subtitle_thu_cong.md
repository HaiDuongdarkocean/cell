---

## 4. Mô tả chi tiết chức năng

### 4.1 Phương thức import

**File picker:**
- Nhấn nút Import → mở file picker
- Chọn file .srt hoặc .vtt

**Drag-drop:**
- Kéo file từ máy thả vào vùng video
- Vùng video highlight khi đang kéo file

### 4.2 Parse và sync

- Parse file subtitle → array `{start, end, text}`
- Sync với video timeline tự động
- Nếu subtitle lệch: người dùng có thể điều chỉnh offset (±30 giây)

### 4.3 Chọn vai trò subtitle

- Sau khi import: chọn vai trò:
  - **Ngôn ngữ học** (hiển thị trên)
  - **Ngôn ngữ mẹ đẻ** (hiển thị dưới)

### 4.4 Encoding

- Auto-detect: UTF-8, UTF-16 LE/BE, Shift-JIS, GB2312
- Nếu không detect được: hỏi người dùng chọn encoding
