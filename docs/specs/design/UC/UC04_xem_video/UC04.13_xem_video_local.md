---

## 4. Mô tả chi tiết chức năng

### 4.1 Mở file video

- File picker: chọn file .mp4, .mkv, .avi, .webm
- Drag-drop file vào giao diện player
- Hỗ trợ mở nhiều file cùng lúc (tạo playlist)

### 4.2 Playlist

- Thêm nhiều file vào playlist
- Sắp xếp thứ tự bằng drag-drop
- Tự động phát file tiếp theo khi hết
- Lưu playlist per-session

### 4.3 Lưu tiến độ

- Tự động lưu timestamp xem dở (mỗi 5 giây)
- Khi mở lại file đã xem: hỏi "Tiếp tục từ [timestamp]?"
- Lưu theo tên file + kích thước file (fingerprint)

### 4.4 Subtitle auto-detect

- Khi mở file `video.mp4`: tự động tìm `video.srt` và `video.vtt` trong cùng thư mục
- Nếu tìm thấy: hỏi "Tìm thấy subtitle [tên file]. Dùng không?"
- Hỗ trợ subtitle nhúng trong .mkv (extract và parse)

### 4.5 Giao diện player

- Mở trong tab mới (full-page player)
- Đầy đủ controls: play/pause, seek, volume, fullscreen
- Floating bar Orca với tất cả tính năng học

## 7. Yêu cầu phi chức năng

- Mở file video < 2 giây
- Lưu tiến độ không block playback
- Hoạt động hoàn toàn offline
- Hỗ trợ file lên đến 10 GB (stream, không load toàn bộ vào RAM)
