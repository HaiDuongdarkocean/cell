## 4. Mô tả chi tiết chức năng

### 4.1 Định dạng file hỗ trợ

| Định dạng | Mô tả | Ví dụ |
|---|---|---|
| Yomichan .zip | Từ điển Yomichan/Jitendex | jmdict_english.zip |
| Plain text (newline) | Mỗi dòng 1 từ | apple\nbanana\n... |
| CSV | word,definition[,example] | apple,"quả táo","I eat an apple" |
| JSON | Array of objects | [{"word":"apple","def":"quả táo"}] |

### 4.2 Quy trình import

1. Người dùng chọn file (file picker hoặc drag-drop vào vùng upload)
2. Hệ thống detect định dạng tự động
3. Hiển thị **preview 10 entries đầu** để người dùng xác nhận
4. Người dùng đặt tên từ điển và chọn ngôn ngữ
5. Nhấn **"Import"** → parse và import vào SQLite
6. Progress bar hiển thị tiến độ import
7. Thông báo hoàn tất với số entries đã import

### 4.3 Validate trước khi import

- Kiểm tra encoding: UTF-8, UTF-16, Shift-JIS (auto-detect)
- Kiểm tra format: nếu không nhận dạng được → hiển thị lỗi
- Kiểm tra dung lượng: cảnh báo nếu file > 50 MB
- Kiểm tra trùng tên từ điển

### 4.4 Xử lý Yomichan .zip

- Giải nén và parse `index.json` để lấy metadata
- Parse các file `term_bank_*.json`
- Hỗ trợ: JMdict, Jitendex, KANJIDIC, pitch accent dictionaries

### 4.5 Giới hạn theo tier

- **Free User:** tối đa 2 từ điển tùy chỉnh
- **Premium User:** không giới hạn [Phase 2]

## 7. Yêu cầu phi chức năng

- Import 100,000 entries trong < 30 giây
- Không block UI trong quá trình import (chạy trong Web Worker)
- Hỗ trợ auto-detect encoding: UTF-8, UTF-16 LE/BE, Shift-JIS
- Rollback hoàn toàn nếu import thất bại (không để data nửa vời trong SQLite)
- Hỗ trợ file Yomichan .zip lên đến 100 MB
