## 4. Mô tả chi tiết chức năng

### 4.1 TTS Engines

| Engine | Mô tả | Yêu cầu |
|---|---|---|
| Web Speech API | Offline, chất lượng thấp | Không cần |
| Edge TTS | Online, chất lượng cao | Kết nối internet |
| Google Cloud TTS | Online, chất lượng cao nhất | API key |

### 4.2 Chọn giọng đọc

- Dropdown danh sách giọng theo ngôn ngữ học
- Preview: nút "Nghe thử" với từ mẫu

### 4.3 Tốc độ và pitch

- Tốc độ: 0.5x – 2x
- Pitch: thấp / bình thường / cao

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Cấu hình TTS | ✅ | ✅ | ✅ | — |
| Google Cloud TTS | ❌ | ✅ | ✅ | — |
