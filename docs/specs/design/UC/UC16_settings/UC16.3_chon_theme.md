---

## 4. Mô tả chi tiết chức năng

### 4.1 Các theme

- **Light:** giao diện sáng
- **Dark:** giao diện tối
- **Auto:** theo system preference (prefers-color-scheme)

### 4.2 Áp dụng

- Áp dụng cho: toolbar popup, Ocean Memory, Reader, tất cả UI của Orca
- Không ảnh hưởng đến trang web đang xem

### Bảng phân quyền hiển thị nút
