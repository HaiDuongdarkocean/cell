## 4. Mô tả chi tiết chức năng

### 4.1 Màu Learning Status (5 màu)

| Trạng thái | Màu mặc định | Tùy chỉnh |
|---|---|---|
| Chưa học | Đỏ nhạt (#FFE0E0) | Color picker |
| Theo dõi | Cam nhạt (#FFE8CC) | Color picker |
| Đang học | Vàng nhạt (#FFF8CC) | Color picker |
| Đã học | Xanh lá nhạt (#E0FFE0) | Color picker |
| Ignore | Xám nhạt (#F0F0F0) | Color picker |

### 4.2 Màu Frequency Tier (5 màu)

Tương tự — 5 color pickers cho 5 tiers.

### 4.3 Preview real-time

- Đoạn văn mẫu hiển thị với màu đang chọn
- Cập nhật ngay khi thay đổi màu

### 4.4 Reset về default

- Nút "Reset về mặc định" cho từng nhóm hoặc tất cả

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Tùy chỉnh màu | ❌ | ✅ | ✅ | — |
| Reset về default | ❌ | ✅ | ✅ | — |
