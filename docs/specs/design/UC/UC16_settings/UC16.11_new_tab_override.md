## 3. Menu / Điểm vào

---

## 4. Mô tả chi tiết chức năng

### 4.1 Bật/tắt

- Bật: mở tab mới → hiển thị Ocean Memory (SRS review)
- Tắt: mở tab mới → trang mặc định của Chrome

### 4.2 Khi bật

- Tab mới hiển thị Ocean Memory với stats và nút bắt đầu ôn tập
- Người dùng có thể gõ URL vào address bar bình thường
