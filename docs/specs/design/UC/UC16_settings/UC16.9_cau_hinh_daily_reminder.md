## 2. Điều kiện tiên quyết

- Người dùng đã đăng nhập
- Đã cấp quyền Chrome notification

---

## 3. Menu / Điểm vào

- Settings → **Notifications** → **Daily Reminder**

---

## 4. Mô tả chi tiết chức năng

### 4.1 Cài đặt

- Bật/tắt nhắc nhở
- Chọn giờ nhắc (ví dụ: 20:00)
- Nội dung thông báo: "Bạn có [n] cards cần ôn hôm nay!"

### 4.2 Chrome notification

- Dùng Chrome Notifications API
- Click notification → mở Ocean Memory

### 4.3 Không nhắc nếu đã ôn đủ

- Nếu đã đạt daily goal: không gửi notification

### Bảng phân quyền hiển thị nút
