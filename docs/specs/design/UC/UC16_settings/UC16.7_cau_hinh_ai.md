## 4. Mô tả chi tiết chức năng

### 4.1 Chế độ AI

| Chế độ | Mô tả |
|---|---|
| **Local (WebLLM)** | Qwen2.5 chạy trong browser, offline, auto-load theo RAM |
| **Local (Ollama)** | Kết nối Ollama server local, fallback khi WebGPU không khả dụng |
| **Cloud** | API cloud [Phase 2] |
| **Auto** | Thử local trước, fallback cloud |

### 4.2 Cấu hình Ollama

- Endpoint URL (mặc định: `http://localhost:11434`)
- Model name (mặc định: `qwen2.5:1.5b` hoặc auto theo tier)
- Test connection

### 4.3 WebLLM

- Tự chọn model theo RAM: Lite (1.5B) / Standard (3B) / Pro (7B)
- Download model lần đầu theo tier (~1-4 GB tuỳ model)
- Hiển thị trạng thái: "Đã tải" / "Đang tải [X]%" / "Chờ tải"

### 4.4 Quota

- Free User: 30 lần AI/ngày (tổng cộng mọi tính năng AI)
- Hiển thị quota còn lại

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Cấu hình AI | ❌ | ✅ | ✅ | — |
| Dùng AI | ❌ | ✅ (30/ngày) | ✅ [Phase 2] | — |
