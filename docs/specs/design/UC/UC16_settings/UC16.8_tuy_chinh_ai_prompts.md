## 4. Mô tả chi tiết chức năng

### 4.1 Năm prompts per language profile

| Prompt | Mô tả |
|---|---|
| Giải thích từ | Giải thích từ trong ngữ cảnh câu |
| Phân tích câu | Phân tích ngữ pháp câu |
| Câu ví dụ | Tạo câu ví dụ cho từ |
| Ngữ pháp | Giải thích điểm ngữ pháp |
| Dịch | Dịch câu sang ngôn ngữ mẹ đẻ |

### 4.2 Biến trong prompt

- `{word}`: từ đang tra
- `{sentence}`: câu chứa từ
- `{native_language}`: ngôn ngữ mẹ đẻ
- `{target_language}`: ngôn ngữ học

### 4.3 Free-text editor

- Textarea để chỉnh sửa prompt
- Preview: test prompt với từ mẫu

### 4.4 Reset về default

- Reset từng prompt hoặc tất cả

### Bảng phân quyền hiển thị nút

| Nút/Chức năng | Guest | Free User | Premium User | System |
|---|---|---|---|---|
| Tùy chỉnh prompts | ❌ | ✅ | ✅ | — |
| Reset về default | ❌ | ✅ | ✅ | — |
