# Popup Dictionary — Toolbar Tab Content Wireframes

> Chỉ bố cục (layout), không màu sắc, không typography chi tiết.
> Mỗi tab: 3 variants × 3 states (empty, no-active, active).

---

## Chú thích ký hiệu

```
┌─────────────┐   khung popup
│ [i]  Label  │   icon button / tab
│ ─────────── │   divider
│ [ ] Text  > │   row có checkbox / action
│ [■] preview │   ảnh/card được chọn (active)
│ [ ] preview │   ảnh/card chưa chọn
│ [  button  ]│   button
└─────────────┘
```

## Tóm tắt bố cục theo tab

| Tab | Variant | Bố cục chính | Chiều cao | Độ phức tạp |
|---|---|---|---|---|
| Audio | A | List dọc theo nhóm | Trung bình | Thấp |
| Audio | B | List + mini-tabs | Thấp | Trung bình |
| Audio | C | Grid card 3 cột | Thấp | Trung bình |
| Image | A | Strip ngang 1 hàng | Thấp | Thấp |
| Image | B | Grid 2 cột | Cao hơn | Thấp |
| Image | C | Hero + thumbnails | Cao nhất | Trung bình |
| Translate | A | 1 result + 1 source card | Thấp | Thấp |
| Translate | B | 2 cột song song | Thấp | Thấp |
| Translate | C | Result + expand source | Thấp | Thấp |
| Links | A | List dọc | Thấp | Thấp |
| Links | B | Chips wrap | Thấp | Trung bình |
| Links | C | Cards theo category | Cao | Trung bình |
