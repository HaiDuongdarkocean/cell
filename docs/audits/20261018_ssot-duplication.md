## Audit claims verified wrong

1. `useLocalVideo.ts` has **no** inline isEditable copy — it already imports `isEditableEvent` (re-exported via `subtitleShortcuts.ts:9`). Only `PlayerModeOverlay.tsx:529` + `sidepanel/App.tsx:247` are real copies.
2. `features/download/downloader.ts:~323` has **no** `btoa` data-URL copy — that line is a comment; the real helper is `downloadSaver.blobToDataUrl` (already counted in C1).
3. QueueTab `formatCueTime` does **not** drop hours into modulo — it emits raw total minutes (`65:00` for a 1h5m cue); still wrong vs canonical `1:05:00`, kept as bug fix.
4. `useDownloadProgress.ts` has **no** sendWithRetry loop (only `useDetectedMedia` has one) — shared hook needs an optional retry.
5. `syncRuntime.broadcastApplied` uses `runtimeDeps.broadcast`, not `ctx.messageBus.broadcast` — shares only the tab fan-out.
6. `fetchMediaUrl.ts:45` is a content-type fallback (`?? kind default`), not an ext→mime ternary — not part of C3.
7. `smiParser.cleanSmiText` already routes through `stripSubtitleTags` — nothing to migrate there (C8 shrinks).
8. `resolveResourceLangCode` does not exist — C21 creates it; the five sites use different fallbacks.
9. `connectAdapter.ts:~236` contains an extra un-reported inline `atob` + ext→mime block (absorbed into C1+C3).
