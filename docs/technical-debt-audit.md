## 11. Recommended remediation priority

1. **Fix trust boundaries** — add Zod `safeParse` to all background handlers (download, subtitle, mediaDetection, sidePanelRelay, cardCreator, settings, youtubeDetection, detectionDispatch).
2. **Harden external fetches** — add `fetchWithTimeout`/AbortController to translate, community audio, quickAdd media, offscreen fetch.
3. **Stop silent failures** — remove empty catch blocks; log or propagate errors in `enrichM3U8Variants`, `downloader` cleanup, `pushAutoLoadSubtitles`.
4. **Split giant files** — start with `contentScriptController.ts` (1,662 lines), then `popupDictionaryController.ts`.
5. **Make popup/sidepanel responsive** — add `@media` breakpoints and fluid sizing.
6. **Replace inline styles with design tokens** — subtitle UI panels should use CSS classes and tokens.
7. **Fix pre-existing `tsc` errors** in `popupShell.ts` and tests.
8. **Clean production debug** — remove `console.log('[DEBUG keydown]')`.
9. **Extract inline SVGs to `ICON_CATALOG`** or formally add stroke-width variant support.
10. **Update `docs/2-architechture-system.md`** to match actual file sizes and module boundaries.
