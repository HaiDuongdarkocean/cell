Design point:
  • Grip tab centered phía trên cluster, dính vào top edge (cùng DOM).
  • Visual: 28×4px pill bar, --color-text-muted @ 35% opacity → 70% hover → 90% active.
  • Hit-area: 44×24px (HIG minimum) — invisible padding quanh visual.
  • Cursor: grab trên tab, grabbing khi drag. Cluster body = default (bỏ move toàn cluster).
  • Drag logic: chỉ qua tab (bỏ border 4px hit-test). Double-click tab → reset vị trí.
  • Collapsed: tab ẩn, cả collapsed circle = handle (không có button inside).
