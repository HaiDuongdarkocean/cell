Design system — Subtitle Manager v4

Import button — góc trái trên, icon upload. aria-label="Import subtitle file". Drag-drop cũng hoạt động. Giữ nguyên vị trí.
Manager icon — bên cạnh import button. aria-label="Subtitle manager". Active = primary color (blue).
Active chip — English #2 · Arabic #1 (thân thiện: tên language + index, không hostname). Max 160px + truncate. Import → en-sub (không extension).
Toast — giữa video, bottom 30%. ✓ Switched to English #1 hoặc ✓ Imported 2 files → Target + Native. System colors (bg + border + success green).

Naming convention (thân thiện, không hostname):

• Auto-detected: {Language} #{N} (vd English #2, Arabic #1) — user chỉ quan tâm language + index, không quan tâm nguồn.

• Imported single: {filename without extension} (vd my-subtitle từ my-subtitle.srt). Max 20 chars → truncate + ….

• Imported multi: {filename} + role tag → Target / → Native trong meta.

Section label thân thiện: Target · English thay Target · EN (full language name, thân thiện hơn).

Panel: 320px width, 2 section collapsible (Target blue + Native amber). Radio button + name + format chip + size. Active = accent border + filled radio. Imported = green "Imported" tag.

Multi-file import: 1 file → detect lang → auto-assign role. 2 files → detect each → assign target + native. 2+ files → first target-lang + first native-lang, rest ignore.

Reload: auto-load ghi đè imported sub (ponytail — imported sub chỉ dùng session hiện tại).

Bug #5 fix: auto-load push mới → giữ activeIndex, không reset về #1.

Case guard: filename >20 chars → truncate + …. Extension .srt luôn bỏ đi (user chỉ quan tâm tên).

Accessibility: aria-label cho mỗi icon/button. Section header rõ ràng Target · English · 3 subtitles.
