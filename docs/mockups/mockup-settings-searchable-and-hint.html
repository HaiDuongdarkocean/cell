Implementation notes (for G1 spec):
  • BUG 1 — SearchableSelect: new atom src/shared/ui/SearchableSelect.tsx. Reuses MultiSelect's filter logic (case-insensitive, matches label incl. native name). Single-select semantics: click option → select + close. Keyboard: ↑/↓ navigate, Enter select, Esc close, type reopens menu if closed. Replaces CustomSelect only for the 2 overlay language fields (others have ≤7 options — no search needed, YAGNI).
  • IMP 1 — Hint icon (floating popover): new atom src/shared/ui/HintIcon.tsx. Pattern: <span class="hintWrap" style="position:relative"><button class="hintBtn"/><p class="hintText" role="tooltip"/></span>. Hint popover is position:absolute; bottom:calc(100%+6px) → floats UP above the icon, does NOT push the control down. Click icon toggles hidden on the popover. Replaces all <p class="asHint"> / <p class="hint"> usages (4 in SettingsDialog, 2 in SubtitleStylePanel). Open state local to component (no persistence — refresh resets, per ponytail). Dismiss: click icon again, or click outside (optional — ponytail: skip outside-click if user didn't ask).
  • Edge cases solved:
    • Theme sync: popover bg = --color-surface-hover, border = --color-border, text = --color-text → đồng bộ light/dark mode.
    • Viewport boundary (3-axis detection):
      • Vertical: if btnRect.top < popoverHeight + 8px, add .flip-top → popover appears below icon instead of above.
      • Horizontal: if spaceLeft < popoverWidth, add .align-right → popover right-aligned to icon.
      • Center: if both sides insufficient (< popoverWidth/2), add .align-center → popover centered on icon.
      • Combined: CSS supports combos like .flip-top.align-right for corner cases.
    • Scroll container: render popover via React Portal to document.body (position fixed) → not clipped by overflow-y: auto on settings panel. Calculate position from icon's rect.
    • Click outside dismiss: useEffect + mousedown listener on document → close if click outside icon + popover.
    • Single popover: parent SettingsDialog state openHintId: string | null → only 1 hint open at a time.
    • Text length: max-width: 280px + natural text-wrap → prevents overflow.
    • Z-index: z-index: 30 → above all panel content.
    • Keyboard a11y: Tab → Enter/Space toggle, Esc to close.
  • No new tokens: reuses --color-surface-hover, --color-border, --color-text, --color-primary, --color-primary-subtle, --color-text-muted, --radius-md, --shadow-md, --transition.
  • a11y: hint button = aria-expanded + aria-label="Show hint for X"; popover = role="tooltip". SearchableSelect = combobox pattern per WAI-ARIA.
