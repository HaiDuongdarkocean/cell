Phiên bản 1

A → 文 (path A, clean arrow)

Giữ concept "A → 文" nhưng chữ A vẽ bằng path (crisp trên mọi host, không bị host CSS override font). Arrow rõ ràng hơn (→ dài hơn). 文 giữ text vì CJK không thể path đơn giản.

Phiên bản 2

Sparkles + A (AI generate)

Sparkles (✨) + chữ A. Gợi ý "AI generate subtitle" — phù hợp action "generate native". Không cần chữ CJK, ý nghĩa rõ qua sparkles (magic/generate) + A (subtitle). Đơn giản nhất, không phụ thuộc font CJK.

Phiên bản 3

Arrows-exchange (translate, no text)

2 mũi tên ngược chiều (→ trên, ← dưới). Gợi ý "translate/exchange" — target ↔ native. Hoàn toàn path-based, không text, không phụ thuộc font. Tối giản nhất, phù hợp mọi host. Giống icon "languages" của Lucide.
