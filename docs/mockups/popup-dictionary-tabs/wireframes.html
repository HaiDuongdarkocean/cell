Popup Dictionary — Final Tab Content Wireframes

  • Toolbar icon buttons show a badge count when items in that tab are selected.
  • All media content (audio, image, translate, links) is lazy-loaded only when its tab is clicked. Target: <2s.
  • Audio: click the speaker icon to play; click the label text to select. No visible checkbox when inactive.
  • Audio label order: Speaker → Dialect/Region → Gender.
  • Image: horizontal filmstrip; no selected-count summary line.
  • Translate: two stacked lines — top target sentence, bottom native translation. Native language is set in Settings > Popup > Native language block.
  • External dictionary: simple vertical link list.
