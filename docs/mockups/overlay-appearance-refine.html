Sự khác biệt:
• Text opacity = mờ icon/text bên TRONG button (text mờ → khó đọc)
• Background blur = mờ video PHÍA SAU button (kính mờ frosted glass) — text vẫn rõ!
• Background opacity = độ đục của bg button (0% = trong suốt hoàn toàn, chỉ có blur)
• Hover = icon đổi sang màu primary (xanh) — không còn viền để feedback

Default: blur=4px, bg opacity=0% (button trong suốt, chỉ frosted glass). Hover vào button để thấy icon đổi màu xanh.
