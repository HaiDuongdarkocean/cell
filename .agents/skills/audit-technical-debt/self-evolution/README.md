# Self-evolution for `audit-technical-debt`

This folder lets the skill improve from real usage. It contains:

- `workflow.md` — when and how to self-correct.
- `RUNBOOK.md` — log of every audit run and observed issues.
- `mutation_prompts.md` — prompts for generating candidate skill mutations.
- `test_cases.md` — scoring rubric and test cases.
- `archive/` — previous versions of `SKILL.md` when a mutation is applied.

Do not edit these files by hand unless you are running the self-correction loop.
