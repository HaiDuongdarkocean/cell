Button

Pill-shaped action control. Supports primary, secondary, outline, ghost, and destructive variants. Touch target 40–44px. Use --button-bg and --button-fg tokens.

Status: stable Level: Atom Category: Action
Variants: Primary Secondary Ghost Destructive
Button is the most common action control. It uses --button-bg for background, --button-fg for text, and --radius-pill for corner. Hover uses --color-surface-hover on ghost/outline variants.
  • --button-bg → var(--color-primary)
  • --button-fg → var(--color-primary-foreground-soft)
  • --button-hover-bg → var(--color-primary-hover)
  • --button-radius → var(--radius-pill)
Use <Button variant="primary">Save</Button> for the main action in a dialog. Use ghost for low-priority actions in a toolbar. Always keep label concise. 
import { Button } from '@/shared/ui';

<Button variant="primary" size="md" onClick={onSave}>
  Save changes
</Button>
