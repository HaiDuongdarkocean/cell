Button

Action

Button atom — CTA uses glass, accent uses primary-subtle. Primary is reserved for focus, active, links, and small chips.

Variants

CTA is glass surface + text. Accent is primary-subtle. Outline/ghost keep neutral. Destructive is red-subtle. Link is primary text.

Active / toggle

Use primary-subtle background for active toggle.

Sizes

Small for dense toolbars, medium default, large for prominent actions.

Vertical (icon + label)

ZaloPay-style bottom navigation: icon stacked above a short label.

Liquid Glass

Frosted glass surface that lifts on hover. Ideal for floating toolbars and panels.

Card surfaces

Cards use surface, glass, or selected state. Selected uses primary border + primary-subtle fill.

Default

Static container.

Interactive

Hover to lift.

Frosted surface.

Selected
