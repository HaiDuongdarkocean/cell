# Self-Evolution for audit-ui-ux-then-redesign

This skill learns from every run. After each audit, brief, or implementation, append one line to `RUNBOOK.md` with:

- Page kind
- What the user actually wanted (post-confirm)
- Which 3 dials worked
- Which audit finding mattered most
- What the agent missed or overdid

When `RUNBOOK.md` accumulates 5+ entries, review `mutation_prompts.md` and run the self-correction workflow in `workflow.md`.
